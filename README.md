# 归墟 Guixu

深海 · 潜艇 · 中式恐怖。Godot 4.7（Forward+）+ Blender 5.2。

## 运行
用 Godot 4.7 打开本文件夹，按 F5。主场景是大厅 `scenes/lobby.tscn`：建房 / 加入（局域网直连）、单人下潜，旧版单人剧情（宿舍 → 办事处）也从这里进。
只想开船的话直接打开 `scenes/deep_sea.tscn` 按 F6（当单人）。

## 联机（`scripts/net/`）
最多 4 人，主机说了算（不架服务器，一个玩家当主机）。
- **联机方式**（`net_backend.gd`）：现在只有 **局域网 / 直连 IP**（ENet，UDP 端口 24680）能用，外网要主机做端口映射；
  **Steam 好友**、**归墟服务器**是占位，按钮灰着，接入时各写一个后端替换掉
- **大厅**（`lobby.gd`）：起名字（存在 `user://settings.cfg`）→ 建房 / 填主机 IP 加入 → 房间里挑岗位（驾驶、声呐、轮机、潜水员；一个岗位一个人，抢了就互换）→ 主机开局，大家一起下井（坐冰井升降机，这一段就是加载画面，见下面「下井」），加载完一起进潜艇。开局以后不能中途加入
- **名单、开局**（`net.gd`，自动加载为 Net）：主机维护玩家名单整张广播；没联网时 `multiplayer` 是 OfflineMultiplayerPeer，自己就是主机，单人走同一套代码
- **舱内同步**（`sub_session.gd`，深海场景里的 Session 节点）：
  - 每个人的第一人称状态每秒发 20 次，别人那边用替身（`crew_puppet.gd`，按对方的时间戳晚 0.12 秒插值播放）带一个 `crew_body.gd` 的身体演出来：走、跑、坐、开门握手轮都有，看得见脸，有脚步声，头顶有名字
  - 潜艇主机算物理，每秒广播 20 次位置、速度和操纵输入；别人那边用同样的输入跟着算、再慢慢拉到主机的位置上。坐驾驶椅的人把输入发给主机，自己这边直接用（不等主机）
  - 驾驶椅（一次只能坐一个人）、探照灯、声呐主动 / 被动、水密门：先问主机，主机定了告诉所有人；门的动作各家本机演，演完和主机对不上两秒以上就按主机的摆过去
  - 巨物（`scripts/giant.gd`）主机算行为，每秒广播 10 次，别人那边插值；吼叫、撞艇是事件。艇壳耐久跟着潜艇状态广播，破了全员回大厅
  - 舱里两个人挨得太近会被推开（过道错得开身，门洞一次过一个）
  - 开局按岗位摆位：驾驶坐驾驶椅，声呐站左舷导航台，轮机站右舷配电柜，潜水员站水密门跟前
  - 右上角船员名单；Esc 放出鼠标时有菜单（继续 / 离开下潜回大厅）；主机退出时其他人回大厅
- **还没做**：语音（打算放进世界观：舱内就近语音、出舱靠水声电话）、中途加入、断线重连、外网穿透

测联机（开两个进程，后台跑、不出声）：
```
godot --headless --audio-driver Dummy --path . --max-fps 60 -- --host --autostart=2 --name=甲 --net-log
godot --headless --audio-driver Dummy --path . --max-fps 60 -- --join=127.0.0.1 --name=乙 --role=3 --net-log --actions=800:interact
```
`--host` / `--join=地址` 开局就建房 / 加入，`--autostart=N` 凑够 N 人自动开局，`--role=0~3` 想要的岗位，`--net-log` 打出 `NET <帧号> <id> ...` 的联机日志。
截别人视角的图：主机照上面那样无头跑（加 `--at=0,-0.4 --yaw=180` 站着面朝后），
另一个用 `python tools/capture.py out.png --scene=res://scenes/lobby.tscn --join=127.0.0.1 --at=0,1.4 --wait=1100`。

## 玩法设计（`docs/design.md`）
2026-10-12 起背景换到木卫二（欧罗巴）冰下海洋：冰震和被人类噪音引来的东西毁了线缆和站点，能延寿的生物质“时间”断供；
4 个被高价征召的菜鸟从 20 公里的冰井下去，开小潜艇沿着断掉的线缆往深处走，见 `docs/design.md`。下面的 1998 年单人剧情不再用，旧文档归档在 `docs/archive/`，只作素材。

## 开场镜头：冰井灯灭（`scenes/intro/shaft_blackout.tscn`、`scripts/intro/shaft_blackout.gd`）
设计文档「八、开场」的第 3 个镜头，第一个做的高画质镜头。站在 20 公里冰井（半径 11 米）第 0 圈走台上，扶着栏杆往下探、斜着往下看：
近处的栏杆和灯是虚的前景，每 12 米一圈的环形走台（镂空的热镀锌压焊格栅，`assets/shaders/bar_grating.gdshader`；
槽钢边梁兼踢脚板、工字钢托梁一头插进冰里、底下三角斜撑撑到井壁上，锚板贴着修平的那圈冰；安全黄扶手顶上被手磨出钢来）
和一圈 24 盏舱壁灯（扶手上伸出横臂，铸铝灯座上拧着朝上的磨砂玻璃罩，外面四根筋的护罩，从上往下看得见发光的罩子）
一路缩进下面的黑暗。每圈的灯整体错开一个随机角度，有几盏坏的、几盏接触不良一直在跳、几盏换成了冷白 LED。冰震（7 秒起：低频轰鸣、冰屑、电压往下沉）→
冰裂（10.4 秒：又一声闷响、掉冰块、墙上开裂纹；11.1 秒画面右上方第 2 圈走台上一根加热管被扯断，一股汽横着喷进井里）→
镜头推长焦看着井底 → 12.6 秒起灯从井底那圈开始一圈一圈往上灭（同一圈里也是一盏接一盏），黑暗从画面中间往外涨；
前沿离镜头的距离按对数匀速缩短（远处几百米一眨眼，越近越慢），涨到占满大半个画面后焦距跟着拉回广角；
黑暗停在脚下那圈，镜头这圈的灯跟着电压塌下去、挣扎两秒才灭，头顶那圈紧跟着灭，全黑。
空气：体积雾（冰震时变浓）、远处按深度没进黑暗（不然长焦看得见井底的硬边圆口）、加热管冒的汽和喷出的汽是粒子
（几十米外体积雾的格子有一米来宽，细的汽会被抹平），喷出来积在那一片的一团是体积雾（`assets/shaders/steam_fog.gdshader`）。
升降机：画面右下方，轿厢（`scripts/shaft/lift_cab.gd`，见下面「下井」）开场时刚从第 1 圈走台下去，顺着导轨每秒 4.5 米往下走，
顶上的琥珀色警示灯转着扫过井壁，底下一盏灯往下照；冰震时在导轨上抖、灯跟着电压沉；冰裂那一下安全器刹死（顿一下、在缓冲弹簧上弹两下，
齿条上崩出一把火星），挂在第 5 圈附近；黑暗涨过轿厢顶的时候和那一圈的灯一起断电。为了让轿厢穿过去，走台在导轨那里的缺口
从 2 米放宽到 3 米多（`ShaftKit.GAP`），井壁上加了齿条、四根滑触线（每 3 米一道绝缘支架），导轨的安装底板加宽到 2.5 米。
场景全部由脚本搭；冰井的模型和材质在 `scripts/shaft/shaft_kit.gd`（`ShaftKit`，和下井共用），网格小工具在 `scripts/shaft/mesh_kit.gd`。
冰壁 `assets/shaders/ice_wall.gdshader`：表面是刀具刮过的毛冰（螺旋切削纹、节缝、融水流痕），
冰里面用实拍的湖冰（ambientCG Ice002 / Ice004，CC0）在三个深度各贴一层、按折射后的视线错开，越深越蓝；
自己写的光照：灯照到的那一片光钻进冰里再透出蓝光（包裹光照），洗墙灯掠过冰面时不会只剩一片暗灰。
冰里一层层气泡多、气泡少的冰层（层面略倾斜）；近处冰面上有霜晶闪点；加热管把贴着它的冰化出一道浅槽。
节缝、刮痕、切削纹、裂纹这些细线按像素宽度抗锯齿（远处不再断成虚线），细到几个像素时不进凹凸（屏幕空间求导会切成一段段）。
圈与圈之间是护笼爬梯：从这圈走台靠井壁的检修口下到下一圈，两个方位隔四格（5.2 米）交替，上一段掉下来的人落在下一圈走台上，
不会顺着检修口一路掉到底。两根扁钢梯梁伸出走台面 1.1 米当扶手，圆钢踏棍每 0.3 米一根（顶上被鞋底磨出钢来），
每 3 米一对支架锚进冰里（梯子背后那一条冰修平了），下面那圈走台面以上 2.2 米起护笼（扁钢箍每 0.9 米一道、5 根竖向扁钢，
最上面一道在检修口里），整副刷安全黄。检修口在格栅着色器里按 `hatch_a` 切掉，补一圈 L50 角钢口框，外圈箱形梁在口子两边断开，
两根短梁从里圈箱形梁伸进冰里托住口框；那一格和左右各一格的洗墙灯挪开两格（走台底下冰上那块最亮的光斑平时被走台挡着，
从口子里露出来，远处是一块块刺眼的白方块）。每段梯子是单独的节点，和走台一样按圈剔除、分三档细节。
每圈冰壁上喷着深度标记「R07 / -84 m」，在冰壁着色器里画：模板字的距离场 `assets/textures/stencil_glyphs.png`
（`tools/gen_stencil_glyphs.py` 拿 Noto Sans SC 800 自动在字腔正中加桥；衬线的 Stardos Stencil 细笔画在开场镜头里只剩一串黑点），
字高 0.42 米，每圈四条：开场镜头左边、上边、右边看得见的地方，和两段爬梯正中间。黑漆旧了褪色发灰、字边深一块浅一块、
字模贴不严漏出的飞边雾点、一片片漆皮剥掉露出冰、冰里冻出来的霜盖住一块块；漆不透光，那里不往外透蓝光。
开场镜头里近处两三圈认得出是字，再远只是一道道灰痕。
灯光：每圈走台底下一排洗墙灯（挂在两根斜撑正中间，光锥边缘软）、前 4 圈每隔一盏一个照走台的短射程灯（镜头附近两圈投影：
立柱、扶手在格栅上拖出影子）、每四盏一个往井里照的灯（照亮空气里的体积雾、冰晶和汽）；更远几圈走台上的一片片光斑、
每圈灯照在身后冰上的那圈暖光（带霜晶闪点）在着色器里算，亮度跟着灯走，灯灭一起灭。
性能：冰壁按两圈走台中间切成一段段、每圈走台是单独的节点（三档细节），引擎按段、按圈剔除，每盏投影灯只重画它照得到的那一两圈
（以前整口井一个 MultiMesh，每盏投影灯都要把五十圈全画一遍）；冰壁不投影；加热管平时冒的汽逐顶点算光、不接收阴影。
Mac M4 上 1600×900：平时 63.6 → 47 毫秒一帧，断管喷汽那几秒 114 → 75 毫秒（投影灯从 18 盏加到 42 盏；以 Windows 独显为准）。
加了爬梯、检修口、深度标记以后多 1 毫秒上下（1~2%；格栅的检修口方向在顶点里算好、标记先按高度筛掉绝大多数墙面像素）。
用 `--bench` 比前后两个版本：改过着色器以后第一次启动要编译管线，慢 2~4 毫秒，每个版本连跑两次取第二次，前后版本交替着跑（机器自己也会越跑越慢）。
声音：井里的空气、灯的嗡声、冰震、钢架呻吟、打火、喷汽是 `tools/gen_sfx.py` 合成的，冰井的回声也在那里按井的几何烘焙
（`*_wet_*`：贴身井壁 10 毫秒、对面井壁每 128 毫秒一簇的颤动回声、上下走台 70 毫秒的散射，加几秒的低频尾巴，跟着干声一起放）。
灯灭时每圈的电闸“咔嚓”是实录（Freesound 131599，CC0，见 `assets/third_party/ASSET_LICENSES.md`），
卷上 `tools/bake_shaft_rir.py` 用 pyroomacoustics 按冰井真实尺寸算的、这一圈接线箱到镜头的冲激响应，51 圈各一条（`relay_ring_*`）：
从近到远的响度、闷的程度、回声多少都是算出来的、连续变化，不分档；按距离晚到（声速 343 m/s）。
RIR 缓存在 `.tmp/shaft_rir.npz`（不进 git），重算：`python tools/bake_shaft_rir.py` 再 `python tools/gen_sfx.py relay_ring`
（要 pyroomacoustics：`pip install --user pyroomacoustics`）。冰块落到走台上不出声（冰砸铁格栅的声音合成、实录都不像，先不要）；加热管的“嗒”、冰裂的“啾——”也去掉了。
调试：`--shot-t=秒` 定在某一刻截图（`--shot-run` 从那一刻接着走）；`--lookdev[=弧度]` 站在走台上近看井壁（调冰的材质用）；
`--cam=r,方位,高,看的点r,方位,高` 换机位，配 `--dof=off`（近景不虚）、`--fov=度`（焦距定死）看灯具、走台底面；
`--near-lit=k` 前几圈挂真的照走台的灯、`--shadows=off` 关投影、`--bench` 量平均帧间隔（比性能用）。
ambientCG 直连很慢（几十 KB/s），下素材前先开代理（`python tools/fetch_ambientcg.py --proxy …`）；下不完就再跑一遍，会接着下。

## 下井：冰井升降机（加载画面，`scenes/lift_ride.tscn`、`scripts/shaft/lift_ride.gd`）
设计文档「八、开场 · 下井」。电脑上匹配好、主机点开始，所有人直接出现在冰井升降机的轿厢里往下走——这一段就是加载画面：
进来的同时后台线程加载下一个场景（`Net.GAME_SCENE`，现在是潜艇，以后是井底的前进基地），各自加载好了告诉主机（`Net.ride_mark_ready`，
主机把谁好了广播给大家）；所有人都好了、而且坐够 12 秒，主机说到站（`Net.ride_go`），大家一起黑场、字幕「一小时后 / 井底 · −20 000 m」、
进下一个场景（`Story.goto_scene` 直接用后台加载好的 PackedScene）。不能走动、没有按钮：坐在两侧的折叠凳上用鼠标转头看
（`RoomWalker` 锁住、坐着），座位按岗位分（驾驶、声呐在左边，轮机、潜水员在右边）；队友是替身（`crew_body.gd` 的身体坐着，
头顶有名字），头跟着他们的鼠标转（每秒 10 次，`Net.send_ride_look`）。屏幕下方一行小字：下井中 / 等队友。
- **轿厢**（`scripts/shaft/lift_cab.gd`，`LiftCab`）：齿轮齿条自爬式（像施工升降机）。20 公里没法用钢丝绳吊（现实里一段提升最多三四公里），
  轿厢挂在井壁方位角 0 的两根 T 形导轨上，背后驱动架上两台电机经减速箱带小齿轮咬着导轨中间的齿条往下爬，电从井壁上的滑触线取，单程一个多小时。
  净空 2.4 × 2.0 × 2.3 米：朝井心那面是钢丝网（三块网片、两根竖撑、腰上一道横撑、里面一道黄扶手），看得见整口井；
  左右前半截是网片、里面靠着折叠长凳（一边两个座位），后半截是黄色推拉门（停在某圈时对着走台的断头），挂在门顶的轨道上；
  背后是实心钢板墙：操纵箱（七段数码管显示深度、上行 / 下行 / 停止、急停蘑菇头、钥匙开关）、对讲电话、电气柜（当心触电）、
  灭火器、电铃、铭牌「06 号升降机 · 额定载重 2000 kg · 限乘 12 人」、「运行中严禁扒门」；顶棚两盏带护网的日光灯（偏绿的冷白，
  前面那盏投影：灯光穿过钢丝网在走台、冰上照出一格格的影子）、检修口。顶上一圈护栏、一盏旋转的琥珀色警示灯，驱动架伸出顶板 1.4 米，
  两台电机横着朝井心；导靴上中下三组（侧轮夹着导轨腹板、面轮顶着腹板的边）、防坠安全器、集电器；底下一盏往下照的灯。
  漆是褪了色的信号橙（掉漆露出红丹、再露出钢，朝上的面结霜），里面是浅灰绿。`detail = 1` 是开场镜头里远看的版本（灯少、不投影）。
  钢丝网 `assets/shaders/wire_mesh.gdshader`：50 毫米网孔、3.5 毫米圆钢丝，镂空用 alpha scissor + alpha to coverage，
  钢丝不到一个像素宽时抖网点（远处是一层淡淡的网，不会整片消失）。标牌用黑体：`tools/gen_sign_font.py` 从 Noto Sans SC 取 700 字重、
  只留 `lift_cab.gd` 字符串里用到的字，存成 `assets/fonts/NotoSansSC-Signs.ttf`（24 KB），加了新字要重跑。
- **井是跑步机**：轿厢停在原点（地板面 y = 0），冰井每秒 5 米往上滚，头顶 9 圈、脚下 12 圈，滚出头顶的那圈挪到最下面换成新的圈号；
  每圈的灯怎么排、哪盏坏了、哪盏接触不良按圈号定（同一圈每次都一样）。冰壁的网格 8 段一循环（`ShaftKit.wall_chunks` 的 period：
  半径在 r(y) 和 r(y + 96 米) 之间渐变，首尾接得上，法线也接得上），近处 25 厘米一行、远处 1 米一行；冰壁着色器的 `tex_y` 把每段挪回
  真正的高度（每 960 米取一次模，免得 float 精度不够），冰里的花纹在段与段之间接得上；`ring_base` 让标记写真正的圈号、深度
  （「R1666 / -19992 m」，圈号最多 4 位、深度 5 位）。灯：离镜头 30 米以内的圈挂真的灯（洗墙灯、往井里照的灯、缺口两边照走台的灯，
  15 米以内这几盏投影），再远到 110 米每圈只留每四盏一个洗墙灯（亮度顶上其余几盏），更远交给着色器；按距离渐变，圈滚过来时不跳。
  空气里的冰晶一粒粒从脚下往上飘过去（看得出在动）。
- **声音**：井里的空气、顶上驱动电机的嗡声（3D）、日光灯的嗡嗡声、一圈灯从身边擦过时灯嗡声大一点，时不时轿厢吱嘎一声；到站时电闸一声。
- **调试**：`--scene=lift` 直接从这里开始（单人）；`--ride-hold` 一直坐着不到站；`--ride-still` 轿厢停着不动（截图，配 `--depth=米`）；
  `--seat=0~3` 坐哪个座位；`--ride-look=度,度` 视线相对座位朝向偏多少（左边的座位 + 是往井心转）；`--ride-crew=N` 单人时往空座位上放
  N 个假队友（到站不等他们）；`--ride-next=场景` 到站以后进哪个场景。Mac M4 上 1600×900 三四十帧（以 Windows 独显为准）。

## 巨物（`scripts/giant.gd`）
第一个巨物，暂名「闷雷」：四十二米长的大嘴掠食者（参考潜渊症 Charybdis 那类，外形原创），头占四成，地包天、满嘴往里倒钩的长牙，下颌三对獠牙闭嘴时也露在外面，张嘴 72° 能吞下整条艇；没有眼睛（两个长死了的疤坑），靠听声音找东西。打不了，只能躲。
- **它听什么**（`Submarine.noise_level` / `make_noise`）：主动声呐每转一圈的 ping（噪音 1.0，400 米外都听得见）、螺旋桨（满速 0.35）、
  压载泵（升降时 0.12）、撞东西、水密门砸上。停车漂着几乎听不见
- **它怎么动**：游荡 → 听到了过去看看（离得远听不准）→ 离得近、还在响就吼一声冲过来撞（艇壳掉三分之一，三下就破）→ 冲过头游开，过一会儿回来听。
  半路没声了就扑空，在附近兜圈子找，找不到就走。不冲的时候从艇顶上游过去，艇壳跟着吱嘎作响、镜头轻晃
- **怎么躲**：Q 关掉主动声呐（被动声呐不出声，屏上只显示声音来的方位，自己越吵越听不清）、停车、别撞东西
- **看得见的**：舷窗封着，舱里只能靠声呐（主动声呐上一大团硬回波，被动声呐上一片亮扇区）、声音（低沉的游动声、吼叫、撞艇）和震动。
  出舱视角、舱外视角（Tab）才看得见它本身：在深海的水和雾里，十几米内被探照灯照到才看得清
- **模型**（`blender/scripts/gen_giant.py`，部件在 `blender/scripts/giant/`，规格 `giant/spec.py`）：颅、下颌、牙、嘴里、躯干和鳍、长须六个部件
  各自程序化生成，总装烘曲率顶点色、合成一个蒙皮网格（约 21 万三角面）、建骨架（脊椎 16 节、尾鳍 2 节、下颌、两根长须各 6 节），
  导出 `assets/models/giant.glb`。`python tools/rebuild_models.py giant` 重新生成；`--preview=目录 --jaw=度` 出 Workbench 预览图
- **材质**（`assets/shaders/giant_*.gdshader`、`assets/materials/M_Giant*.tres`）：苍白透血管、能透光的皮，湿红的嘴里，发黄带裂的牙，
  结壳的骨板，透光的破鳍膜；骨骼会动，所以只用 UV（按米）、全身坐标 UV2 和曲率顶点色，不用三平面投影。
  看样场景：`python tools/capture.py out.png --scene=res://scenes/dev/giant_lookdev.tscn --shot=maw --jaw=65 --light=front`（机位、灯、参数见 `scripts/tools/giant_lookdev.gd`）
- **动作**（`scripts/giant_motion.gd`）：骨骼程序化驱动——大头稳、行波从身体中段传到尾鳍；转弯整条顺着弯；冲刺时离艇越近嘴张得越大、头往上仰，
  撞上的瞬间猛地合上再甩头；吼叫时张嘴；长须有惯性拖拽。碰撞是沿脊椎跟着骨骼走的胶囊
- 艇壳掉到 75% 以下漏水灯闪，40% 以下常亮；破了全员回大厅
- 调试：`--giant=off`、`--giant-at=dx,dy,dz`、`--giant-still`、`--giant-log`、`--giant-pose=charge|moan|ram`、`--giant-jaw=度`、`--giant-yaw=度`、`--giant-light`（其余见 giant.gd 头部）、`--sonar=passive`、`--hull=0.5`、`--no-wreck`。
  无头跑行为（不出声、比实时快）：`godot --headless --audio-driver Dummy --path . --fixed-fps 60 --quit-after 7200 -- --scene=deep_sea --giant-log --giant-at=0,0,-120 --cruise=0.4`

## 破舱（原型，`scripts/breach.gd`）
设计文档「七 · 破舱」的第一版：外面一只带骨刺的东西撞了两下、爪子刮过艇壳，然后一根骨刺扎穿控制舱舱顶（两组管子中间、两盏顶灯之间），
顺着艇壳斜着锯开一道一米长、最宽三十多厘米的口子再抽出去，海水像瀑布一样砸进过道，水位往上涨。
外面那东西本身、联机同步、水往另一个舱流、没穿服的人当场死都还没做（骨刺只是一截占位）。
- **过程**：第一下撞（闷响、整条艇嗡、灯闪）→ 1.1 秒第二下更重（艇壳顶出两道爪尖的裂痕）→ 1.7 秒爪子从外面刮过（尖利的刮擦，镜头一直抖）→
  2.7 秒骨刺扎穿：尖捅进舱里三十厘米，顺着缝锯过去（0.55 秒），锯开的地方两边钢板往舱里翻；骨刺插着的时候堵住大半个缝，水只从两边滋出来，
  抽出去的一瞬间整条缝的水幕全开 → 按进水量涨水：先灌舱底，再漫过地板；泡到水的灯打火、熄掉（最后全黑）；
  缝没进水以后水幕变成水下的一团白、水面翻起一片；舱里的空气压到外面的压力（冰底约 240 个大气压，1/240）就不再进水，顶上留一层几厘米的气。
  进水量 `inflow` 默认 1.2 立方米/秒（乘锯开的比例）；真实的要快几十倍，一两秒就满
- **口子**：艇壳着色器拆成了 `worn_surface.gdshaderinc`，`worn_surface_breach.gdshader` 定义 `BREACH` 后多一道缝：沿缝 48 个采样点的半宽和中线偏移（锯齿边）、
  锯到哪了（`breach_cut`）、缝外一圈崩掉的漆、两道爪痕；只在出事那一刻给内壁那块材质换上（平时的材质不带 discard）。缝横穿两道肋骨，肋骨不切。
  翻进来的两片钢板是脚本生成的网格：内表面舱里的漆、外表面艇壳的黑漆、断口新鲜的钢（外缘的断口单独一层、平滑法线），绕缝边弯成一段圆弧、被挤皱。
  骨刺是一根扁的弯锥（`creature_claw.gdshader`：发黑带油光的角质，尖上磨白）
- **水**（着色器都 include `flood_common.gdshaderinc`：把视线落在“耐压舱圆筒里、这个舱的前后范围里、水位以下”那一段的长度算出来，按浑水衰减）：
  `flood_surface.gdshader` 水面（细分平面，舱外的部分按圆筒、艏部半球丢掉；碎浪、白沫、贴着东西的一圈沫；透过水面的东西按折射挪、按水深发浑，反射交给光照；
  从下面看是斯涅尔窗 + 全反射）、`flood_post.gdshader` 全屏（水下的东西按水深发浑；头没进水里时整个画面糊、晃、发浑）、
  `breach_jet.gdshader` 水柱（越往前越粗越散的一根管子，纹理顺着流向跑）、`flood_particle.gdshader` 粒子（顺着速度拉长的水滴、炸开的一团白、飘满半个舱的水雾、水下的气泡），
  再加一层体积雾让顶灯在水雾里出光锥。全屏后处理放在第 19 层（第一人称相机不画第 20 层，见下面）
- **人**：蹚水按水深变慢（到胸口只剩三分之一，`cockpit_camera.gd` 的 `wade`）；头在水里时隔几秒从嘴边冒一串气泡
  （气泡是 `flood_bubble.gdshader`：不吃灯光颜色的银白亮边，之前跟着光照走，舱里只剩红色夜灯时整串发红）
- **声音**：用 ElevenLabs 生成（`tools/gen_sfx_el.py`，原始文件和每条的描述在 `assets/third_party/elevenlabs/`），`tools/gen_sfx.py` 的 `*_el` 挑版本、加工：
  `creature_ram` 撞艇（两个变体轮流）、`claw_scrape` 爪子刮过、`claw_pierce` 骨刺扎穿锯开（叠 `breach_burst` 的水爆）、
  `breach_jet` 水幕（循环，原始的太亮，压掉一点高频、补低频）、`flood_churn` 翻腾的水（循环）、`underwater_roar` 头在水里听到的（循环，直接放在 Master 上）。
  原来 numpy 合成的版本还在（`*_synth`，对比用）；`breach_strain`（上一版“艇壳被压到崩开”的渐强吱嘎，现在不用了）也留着。密钥放在 `~/.config/guixu/elevenlabs_key`（或环境变量 `ELEVENLABS_API_KEY`），不进 git；
  已经生成过的文件不重复生成，`--list` 只看要花多少积分。实测大约每秒 9 积分。
  耳朵进水时 `Cabin` 总线低通到 320 Hz、压低 12 dB（`sub_audio.gd`）；舱里进了水就不再响漏水的嘀嗒
- **调试**：`--breach=秒` 开场这么多秒以后开始，游戏里 Ctrl+B 现在开始；`--breach-open` 跳过前面直接到骨刺抽出去以后；
  `--breach-freeze=秒` 停在过程的这一刻（看骨刺）；`--no-jet` 不画水幕（看口子本身）；`--flood=米` 开场水位（舱内局部 y：舱底 -1.35、地板 -0.9、
  站着的眼睛 0.72、舱顶 1.35）；`--flood-rate=立方米每秒`（0 = 水位定住，按阶段截图用）。例：
  `python tools/capture.py out.png --giant=off --breach=0.2 --breach-open --no-jet --flood=-1.0 --flood-rate=0 --at=-0.1,0.45 --yaw=-175 --pitch=62 --fov=40`（抬头近看口子）；
  `python tools/record.py .tmp/breach 40 --giant=off --breach=1.0 --at=-0.15,-0.05 --yaw=-172 --pitch=38 --look=480:720:0:-14`（整个过程：先看着舱顶，再低头看水涨）
- 性能：Mac M4 上 1600×900 同一个机位 19 → 14 帧（水柱、水面、粒子、全屏后处理一起多十几毫秒；以 Windows 独显为准，还没优化）

## 舱外的水（`scripts/water_fx.gd`）
- **水体吸收**：全屏后处理按光程衰减颜色，红光最快、绿次之、蓝最慢，东西越远越偏蓝绿、越暗（`assets/shaders/underwater.gdshader`）。
  耐压舱里是空气，不衰减；系数在 `water_fx.gd` 的 `absorption`，几个水下着色器共用
- **光柱**：探照灯在体积雾里打出光柱。体积雾的各向异性只有 0.35，从舷窗顺着侧灯往外看也看得见光
- **颗粒**：海雪、细悬浮物两层颗粒绕着相机铺开，颗粒本身固定在世界里随洋流漂，只有被灯照到才看得见（迎着光最亮）；
  艇开起来颗粒会拉成拖影从舷窗外划过去（`assets/shaders/marine_snow.gdshader`）
- **生物发光**：零星几个蓝绿色的小光点，隔一阵亮一下再熄掉，关了探照灯才看得清（`assets/shaders/bioluminescence.gdshader`）
- 舱外视角的补光是一盏对着艇身的聚光灯（像跟拍的水下机器人），只照得到艇和艇底下一小片海床

## 舱内布局
耐压舱是一段横躺的圆筒（内径 2.7 米），加上艏部半球，长约 8 米，中间一道带水密门的隔壁分成两段：
- **控制舱**（前段）
  - 艏部是驾驶台：一体式三段环绕操纵台（主板正对驾驶椅，左右翼板往驾驶椅方向折 30°，转角共用立柱，
    下沿一道人造革扶手台沿，上沿一道帽檐），上方顶板报警灯牌，桌上操纵杆，前面是驾驶椅
    - 主板正中是机架式主动声呐显示器：圆形显像管、方位刻度环、遮光檐。声呐真的在扫：换能器每转一步往该方位打一扇射线，
      海底连成一片、礁石沉船回波强且后面留声影，艏向朝上显示，带余辉、距离环、电子方位线和读数（`sonar_display.gd`）
  - 驾驶台后面左右各一个舷窗
  - 两舷是嵌在舱壁里的连续工作台，开间由肋骨分隔：右舷依次是配电、生命支持、液压站、舱内环境；左舷依次是神龛、导航、照明配电、水声通信
  - 后端是中间隔壁：水密门、氧气瓶（紫铜管沿隔壁、舱顶接到生命支持柜）、接线盒（线顺着隔壁爬进左舷桥架）
  - 头顶：五根管子（通风、冷却水、消防水、回水、高压空气）从中间隔壁的穿舱套管出来，每道肋骨一个吊架，
    到驾驶台上方往上弯、经穿壳接管座穿出耐压壳（通风管是往下弯，接一个对着驾驶员的球形风口）；
    两舷是梯式电缆桥架，电缆平铺在横档上，从后隔壁的穿舱框（MCT）一路穿过中间隔壁，到艏部整排垂进驾驶台两边高机柜顶上的过线板；
    壳体上三个电缆穿舱件的线从外侧翻过边梁并进桥架
- **水密门**：快速水密门，门洞是 60×140 厘米的圆角矩形（圆角半径 20 厘米，门槛离地 25 厘米）——中间一个手轮，经铸铁减速箱带动曲柄盘，六根连杆（带花篮螺母）同时拨动门扇四周的锻钢压紧把手，
  把手压在门框外圈的楔块上，门扇背面的胶条压在门框的刀口上；门框外两面焊补强板（鱼鳞纹角焊），门轴在左舷（两个粗铰链，带黄油嘴）。
  门扇是 18 毫米钢板，正面一圈包边、一圈加强环，背面 T 型横筋加竖筋；楔块旁刷着把手编号，把手尖和楔块外各一道红漆对位线；
  曲柄盘上的指针对着手轮下面的「关 / 开」黄铜指示牌。
  走到门前（两边都行）脸朝着门按 E 开门 / 关门（`scripts/watertight_door.gd`，连杆机构在脚本里按四连杆实时解算）：
  - 开门：先使劲掰手轮（把手咬在楔块上只挪几度），掰动了把手一起蹦开，再一把一把拧开；胶条“啵”地松开一条缝，门扇起步慢、荡开、略过头再回来
  - 关门：先拉一把、靠惯性甩过去撞上门框，弹回来一点又贴上（把手、手轮被震得晃几下）；再一把一把拧紧，
    把手骑上楔块后越拧越沉、每把转得更少，换手时手轮被顶回来一点，最后一把咬死上锁
  - 门往控制舱一侧开；门关着两段舱互不相通，过门时会低头
- **生活舱**（后段，`blender/scripts/quarters.py`）
  - 门后是过道：右舷小厨房（水槽、电炉、电饭锅、吊柜），左舷两个衣柜；头顶是出入舱口，直梯立在过道中间
  - 中段两舷各一组上下铺（布帘、床头灯）
  - 最后面右舷储物架、左舷洗手池和镜子；后隔壁上是封死的机舱检修门
- 尺寸都写在 `blender/scripts/cockpit.py` 开头；能站的区域在 `scripts/cockpit_camera.gd` 开头的几个矩形里，改布局时两边要一起改

## 捏脸（`scenes/character_creator.tscn`、`scripts/ui/character_creator.gd`、`scripts/crew_look.gd`）
大厅里名字旁边、房间里都有「捏脸」：左边选性别、预设（几个国家的船员）、随机；右边分页调——脸型、眼睛、鼻子、嘴、头（耳朵、头型、喉结、年纪、不对称）、
肤色（深浅、冷暖、红润、性别特征、胡茬）、发型眉眼（7 种发型、14 种眉毛、眉毛浓淡、睫毛、瞳色、发色）、妆容（眼线、眼影、腮红、口红和颜色）；
中间是自己的船员，拖动转身、滚轮拉近，下面切正脸 / 侧脸 / 全身。保存进 `settings.cfg`，在房间里的话主机跟着更新，联机时随名单发给所有人（`Net.local_look`、`Net.look_of`）。
- **样子的数据**（`crew_look.gd`）：一个 Dictionary——性别、各个捏脸形态的值、肤色和妆容参数、几个下标（眉毛、发型、瞳色、发色、口红色……）；
  `sanitize()` 补默认、夹范围（联机收到的、存档读出来的都过一遍），`apply()` 套到身体模型上：设头、口腔、头发的形态键，换材质参数，手的肤色跟着脸走
- **头**（`blender/scripts/gen_head_vitruvian.py`，先跑 `python tools/fetch_vitruvian.py`）：Vitruvian（CharMorph 的写实角色，CC0），男女同一套拓扑。
  只留头、脖子、眼睛、口腔；84 个捏脸形态（`ID_`）、46 个表情（`EX_`：眨眼、视线、瞳孔、眉毛、笑、口型）；睫毛是粒子毛发转的细带子，
  眼部遮蔽（眼皮底下压暗眼球）、泪线；头发是发型引导线插值出来的发片。都按最近的皮肤三角形绑定，每个形态跟着走
- **材质**（`assets/shaders/crew_*.gdshader`）：皮肤两张反照率（浅、深）插值出肤色，扫描的法线上叠平铺的毛孔，胡茬、头皮发茬、眉毛（14 种按发丝画的贴图）、
  眼影 / 眼线 / 腮红 / 口红一层层叠，次表面散射按厚度；眼球一个不透明材质画完眼白和虹膜（虹膜按视线错开，假的折射），
  不用透明的角膜层、不用清漆、捏脸场景不开辉光——这三样都会让虹膜蒙一层灰白
- **调试**：`--scene=creator` 直接进捏脸；`--cc-preset=N`、`--cc-view=face|side|body|back|eye`、`--cc-yaw=度`、`--cc-ui=off`、
  `--cc-set=形态:值,...`；`--cc-shots=all` 把预设挨个拍正脸、侧脸（存到 `.tmp/faces`），`python tools/face_sheet.py .tmp/faces` 拼成对比图；
  游戏里 `--look=N` 本机用第 N 个预设，升降机 `--ride-faces=a,b,c` 给假队友换脸

## 第一人称（`scripts/cockpit_camera.gd`、`scripts/crew_body.gd`）
- **步伐**：按实际挪动的距离走步伐相位，步频随速度变（走 1.25 米/秒约每秒 1.7 步，跑 2.5 米/秒约 2.6 步，和动作捕捉的动画一致）；
  起步迈出半步就落脚，停下时一步迈到一半以上的会把后脚收过来落一下。跑起来镜头起伏更大更尖、视野略宽；门洞跟前跑不起来
- **身体**：低头看得见自己的身子、腿脚和双手——Microsoft Rocketbox 的工装角色（MIT），男女各一套（`crew_body_m.glb`、`crew_body_f.glb`），
  工装改成深海军蓝、反光马甲压成深色、劳保鞋改成黑皮靴（`blender/scripts/gen_crew.py`，先跑 `python tools/fetch_rocketbox.py` 下载原始素材）。
  头是捏脸用的 Vitruvian（见下面「捏脸」），第一人称时只有镜子里看得见，调试用 `--blink=1` 看闭眼。站、走、跑、坐四段动画，
  走和跑按步伐相位定位到动画里对应的时刻，左右脚落地和脚步声对得上；坐在驾驶椅上是坐姿、手搭在腿上。
  每帧让模型的头骨落在眼睛后下方，头不渲染；身体不投影（会让照得到它的舱内灯每帧重画阴影图）
- **开关门**：走到手轮跟前、低头探身，双手握在手轮上一把一把拧（`TwoBoneIK3D` 拉手臂，手掌转到握轮缘的朝向、手指弯起来），
  换手时沿轮缘滑回去；控制舱这边门扇朝人甩过来，开门时往右后方让开，关门时先站在右后方伸手够，抓住手轮推上，再上前拧紧。
  调试用 `--body-preview` 把身体摆到视线前方看姿势

## 声音（`scripts/sub_audio.gd`）
音效全部是程序化合成的（`tools/gen_sfx.py`，只用 numpy），写到 `assets/audio/`；`sub_audio.gd` 负责摆位置、按游戏状态调音量音高。
- **环境声**：艇体低鸣（深水压在耐压壳上的低频）、头顶球形风口的出风、右舷配电柜的变压器嗡声、
  闪烁的那根坏灯管的电流声（音量跟着灯闪）、漏水滴到地板积水里的“嘀”（和水珠落地的时刻对齐，见 `cockpit_props.gd`）
- **航行**：推进电机（音高跟转速）、艇外水流（跟航速）、螺旋桨搅水（七叶桨的叶频）、按住上浮/下潜时的压载泵（有起停爬升）
- **艇壳**：每隔一阵来一声低沉的吱嘎或“嘣”，升降、转向时更勤；撞礁有整个艇壳的嗡鸣和刮擦
- **主动声呐**：扫描线每转回艏向一圈 ping 一声（从艏部换能器方向传来）：950 Hz 的低沉纯音，后面是海里多径反射的长余音，2 秒后一声远处回波
- **交互**：水密门（掰手轮时机构绷紧的闷哼、把手从楔块上蹦开、减速箱齿轮咬合和摩擦、胶条松开的气压“噗”、
  铰链低沉的“嘎——”、门扇快关上时挤出的风、撞上门框的重击（门扇最低六十赫兹的“咚”、隔壁和艇壳的低频轰鸣、金属余音、气压一压、把手叮当）、
  弹回再贴上的一下、拧紧时把手在楔块上刮、最后上锁：把手压死的一串闷响 + 减速箱顶到头的“哐” + 棘爪落下的“咔哒”），
  脚步（按落脚的地面挑：过道中间的扁钢格栅——一串很密的亮“嚓”、格栅在框上颠一下；两边 6 mm 花纹钢板——板的模态、底下空舱的嗡声、
  没压实的钢板在龙骨上磕一下；门洞里的厚钢门槛——闷而短的“咚”。走路脚跟先着地、脚掌跟着落下，跑步更硬更快、最后蹬地蹭一下，
  停下时收脚轻轻一放；每一步都带工装布料擦一下的沙沙声）、探照灯拨杆开关
- **总线**（`default_bus_layout.tres`）：`Cabin` 舱里的声音（小钢舱的短混响），下面分 `CabinFwd`、`CabinAft` 两个舱，
  水密门关着时听者不在的那个舱隔着门闷掉；`Sea` 艇外的水声，在舱里只剩隔着艇壳的低频，贴近舷窗亮一点。
  切到舱外视角时反过来：舱里的声音闷掉，水声全开。Master 上一个 -1 dB 的限幅器
- 循环音在 Godot 里导入成不压缩的 PCM，循环终点后面接了 16 个循环开头的采样：默认的 QOA 压缩、
  以及变调时插值读到终点之后，都会让每圈接缝处出一个毛刺（`gen_sfx.py` 里有说明）

### 不用耳朵检查声音
`python tools/record.py` 用 Godot 的 Movie Maker 离线录一段（固定 60 帧/秒逐帧渲染，音频直接混进文件，**不经过声卡，绝不出声**），
`--actions` 按帧号自动按键；`tools/audio_report.py` 分析录音：响度（LUFS、真峰值、削波）、每 0.5 秒的响度、
孤立的咔哒声（接缝、硬起停、断音）、每个音效事件在录音里的起音延迟和显著度（< 6 dB 基本就是被别的声音盖住了），
可以输出频谱图。`--only-sfx=` / `--mute-sfx=` 只开 / 关掉某几种声音，用来单独查某一路。
后台跑的 Godot（`godot_bg.py`）一律用 Dummy 音频驱动，截图、烘焙时也不会出声。

## 岸上的场景（`scripts/story/`）
- **剧情框架**：`story.gd`（自动加载为 Story：剧情标记、转场黑场和章节字幕、播放对白文件）、`dialogue_script.gd`（对白文件解析）、
  `story_ui.gd`（字幕逐字出现、心声灰色、选项、读纸的界面、交互提示和准星点）
- **房间**：`story_room.gd` 是宿舍、办事处共用的部分。房间模型（`gen_dorm.py` / `gen_office.py` 导出）里预留挂点，照着摆：
  `Walk_*` 能站的矩形、`Seat_*` 坐的地方、`Use_*` 能按 E 的东西、`Anchor_*` Poly Haven 道具、`Light_*` 灯、`Decal_*` 贴花、
  `Paper_*` 纸面（换成排好版的贴图）、`Spin_*` 吊扇和钟的指针、`Door_Leaf` 门扇；子类（`dorm.gd`、`office.gd`）配参数、写剧情
- **第一人称**：`room_walker.gd`，和舱里的 `cockpit_camera.gd` 一样不走物理（能站的地方是几块矩形），步伐、起伏照搬；
  `crew_body.gd` 两边共用，岸上签字时右手拿着笔在合同上写、拇指按进印泥再按到纸上（TwoBoneIK）
- **纸**：`paper_doc.gd` 在 SubViewport 里排版（宋体正文、钢笔手写、毛笔字、公章、红手印、手画的红圈、竖排拓片、海图），
  同一张贴图既贴在 3D 的纸上、也在读纸界面里放大——签名、手印写上去两边一起变。纸的发黄、水渍、折痕、泡过水见
  `assets/shaders/paper.gdshader`、`paper_grime.gdshader`
- **沈渡**：`npc.gd`。坐着待机，说话时不时插一段手势；头和眼睛跟着玩家转（眼睛先到、头慢慢跟）；按台词对口型
  （每个字挑一个声母、一个韵母的口型，一秒四五个字，标点处闭嘴）；一直挂着一点客气的笑；故意不眨眼
- **镜子**：`mirror.gd`，反射相机放在主相机关于镜面的对称点、斜视锥贴着镜面，画到 SubViewport 里贴回镜面。
  自己的脸平时不画（相机在头里面），只放在第 20 层，只有反射相机画这一层——宿舍里照镜子才看得见自己
- **声音**：`room_audio.gd`，雨（窗外）、吊扇、日光灯电流声、收音机沙沙声、港湾的水声；脚步按地面挑（水泥 / 水磨石）；
  打雷跟着窗外的闪电晚一两秒到。音效都在 `tools/gen_sfx.py` 里合成。总线多了 `Room`（小房间混响）、`Outdoor`（窗外，闷一点）
- **窗外的雨**：`assets/shaders/rain_glass.gdshader`，雨点按世界坐标排，一颗颗折射背后的画面，攒大了往下淌、拖一串小水珠
- **导出注意**：对白（`*.dlg`）和纸面文字（`*.txt`）是直接按文件读的，导出时要在导出预设的「资源 → 非资源文件过滤」里加上
  `assets/story/*.dlg, assets/story/docs/*.txt`，不然导出的游戏里字幕和纸面都是空的
- **调试**：`--scene=dorm|office|deep_sea` 从这个场景开始（主场景是大厅）；`--flags=a,b` 预设剧情标记；`--read=纸的名字` 开场就拿起这张纸
  （查排版）；`--tube=on` 宿舍开场日光灯就亮着；`--autoplay` 自动把剧情走一遍（自己走位、看东西、选选项，录演示视频用）

- `assets/textures/decals/` 舱内贴花（水渍圈、脚印、锈水、喷漆字……），由 `scripts/tools/gen_decals.gd` 生成；
  贴在哪、多大写在 `cockpit.py` 的 `decals()` 里（导出成 `Decal_*` 挂点）
- `assets/gi/cabin_gi.res`、`cabin_gi_aft.res` 控制舱、生活舱 VoxelGI 的烘焙数据（改了舱内模型要重新烘焙，`rebuild_models.py` 会自动做；舱外视角时舱内 GI 会关掉，免得渗到艇身外表面上）
- `assets/third_party/` 外部素材，授权见 `ASSET_LICENSES.md`；Sketchfab 下载的压缩包放 `sketchfab/_inbox/`
- `scripts/` 游戏脚本；`scripts/import/post_import.gd` 是所有 glTF 导入后的处理（换材质、去 LOD）；
  `scripts/shaft/` 冰井（`shaft_kit.gd` 模型和材质、`mesh_kit.gd` 网格小工具）、升降机轿厢（`lift_cab.gd`）、下井（`lift_ride.gd`）

## 开发环境（Windows）
2026-10 起在 Windows 上开发（之前在 macOS 上，tools/ 原来是 zsh 脚本，见 git 历史）。
- Godot **4.7.2**（版本要一致，否则导入设置、场景文件会被改写）、Blender 5.2、Git LFS（Git for Windows 自带，`git lfs install`）
- tools/ 下都是 Python 脚本（3.10 以上），在 PowerShell、cmd、Git Bash 里都是 `python tools/xxx.py ...`。
  做包装的那几个（截图、录像、烘焙、下载）只用标准库；生成音效、贴图、对比图的要
  `pip install numpy scipy pillow fonttools pyroomacoustics`；录像（`record.py`）、分析录音（`audio_report.py`）还要 ffmpeg（放进 PATH）。
  `winget install Python.Python.3.13 Gyan.FFmpeg.Essentials` 就能装上。设一个用户环境变量 `PYTHONUTF8=1`：中文 Windows 上
  Python 默认按 GBK 读写文件、往管道输出，不设的话中文输出是乱码
- 不用 PowerShell 脚本：PowerShell 调 .ps1 时会把 `--at=0.3,1.0` 里的逗号当成数组分隔符（`1.0` 还会变成 `1`），`--` 也会被吃掉；
  调 python 这类外部程序时参数原样传过去
- Godot、Blender 默认在 `D:\Godot`、`D:\Blender`（也会在 `C:\Program Files` 下和 PATH 里找），装在别处时用环境变量
  `GODOT`、`BLENDER` 指定可执行文件。下面命令里的 `godot` 指 Godot 的可执行文件，命令行里用带 `_console` 的那个能看到输出
- 截图、录像、烘焙的 Godot 开在一个单独的 Windows 桌面上（`tools/godot_bg.py`）：不弹窗、不抢焦点、不出声，
  编辑器烘焙光照贴图时也一样；想看着窗口跑加 `--fg`
- 生成模型、贴花文字用的字体都在 `blender/fonts/`（SIL OFL），不依赖系统字体

## 常用命令
```
python tools/rebuild_models.py                       # 重新生成全部自建模型并导入（潜艇、宿舍、办事处会顺带重新烘焙 VoxelGI）
python tools/rebuild_models.py submarine             # 只生成某几个：submarine seabed dorm office npc
godot --path . --script res://scripts/tools/gen_decal_text.gd             # 重新画贴花的文字底图（会闪一下窗口）
godot --headless --path . --script res://scripts/tools/gen_decals.gd      # 重新生成贴花贴图
godot --path . -- --bake-gi                   # 只重新烘焙舱内 VoxelGI
godot --headless --path . --script res://scripts/tools/setup_project.gd   # 重写输入映射、重新生成材质
python tools/capture.py shot.png --view=external --orbit=40                      # 截图（后台运行、不弹窗；--fg 前台；其余参数见 scripts/debug_args.gd）
python tools/capture.py shot.png --scene=office --at=0.3,-0.26 --yaw=0          # 岸上的场景截图（不给 --scene 就是潜艇）
python tools/record.py .tmp/story 420 --scene=dorm --autoplay --no-hud           # 自动把序章、第一章走一遍录下来
python tools/glb_info.py assets/models/submarine_cockpit.glb [网格名]            # 查看 glb 里的网格、顶点数
python tools/fetch_polyhaven.py --models a,b --textures c,d                      # 下载 Poly Haven 素材（ambientCG 用 fetch_ambientcg.py --ids）
python tools/fetch_rocketbox.py && python tools/fetch_vitruvian.py && blender -b --factory-startup --python blender/scripts/gen_crew.py   # 重新生成船员的身体（男女两套）和捏脸的头（头的脚本改过会先重跑 gen_head_vitruvian.py；npc 同理：gen_npc.py）
python tools/gen_sfx.py [名字前缀...]                                   # 重新合成音效（之后让 Godot 导入一次：godot --headless --path . --import）
python tools/record.py .tmp/door 12 --at=0,2.0 --yaw=180 --actions=30:interact   # 离线录一段画面+声音（.mp4/.wav/.log），不出声
python tools/record.py .tmp/shaft 34 --res=1280x720 --crf=18 --scene=shaft   # 录开场冰井灯灭的镜头（录的时候临时用 override.cfg 把视口降到 --res，免得 AVI 过 1 GB 被截断）
python tools/audio_report.py .tmp/door.wav --log .tmp/door.log --png .tmp/door.png   # 分析录音
```
