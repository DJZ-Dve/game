> 2026-10-11 方向调整：从单人线性剧情改成 **4 人联机合作**，加入岗位分工、出舱、深海巨物、局内资源管理、船坞升级和局外成长。

## 一、定位

**4 人合作深海恐怖。** 一群走投无路的人，接下一家来路不明的公司开出的高价合同，开着一条舷窗被封死的老潜艇，一次次下到归墟海沟里打捞东西。
看不见外面，只能靠彼此喊话；海里有比潜艇大得多的东西，打不过，只能躲。

### 设计支柱
1. **看不见外面** ✅ —— 舷窗封死是核心设定。外面的情况被拆给不同岗位，**谁都只握着一部分信息**，必须开口配合。
2. **人打不过海** ✅ —— 能反制，不能征服。巨物只能躲、只能逃，小东西才能打。
3. **每次下潜都在算账** ✅ —— 氧气、电、艇体、消耗品、带回来的货，什么都有代价，“留着还是现在用”是持续的压力。
4. **每次回来都更深一点** ✅ —— 船坞升级让艇能下得更深、待得更久，真相也跟着一层层往下。

## 二、一局的流程

```
大厅（办事处）        接合同：目标物、海域、深度、本单的“怪条件”、报酬
    ↓
船坞                  整备：修艇、升级舱位、车间自制装备、补给消耗品
    ↓
出港 · 下潜           封窗航行，靠声呐和仪表找目标
    ↓
作业                  找到目标、出舱、挂钩、采集；躲避或驱赶海里的东西
    ↓
上浮 · 返航           带回多少算多少；全灭则货物丢失
    ↓
结算                  钱 → 船坞；局外点数 → 个人成长；线索 → 剧情推进
```

## 四、四个岗位

核心是**信息不对称**：每个岗位只看得到一部分，必须喊话。

| 岗位 | 负责什么 | 掌握的信息 | 反制手段 |
|---|---|---|---|
| **驾驶** | 操艇、深度、压载、上浮、紧急抛载 | 只有仪表——外面是什么样，全靠别人说 | 关机静默、躲进裂缝、紧急上浮 |
| **声呐 / 导航** | 主动、被动声呐，海图，找目标，监听生物 | 唯一能“看见”外面的人。**主动声呐一开会暴露位置** | 决定开不开声呐；放噪音诱饵 |
| **轮机 / 损管** | 电力分配、氧气、堵漏、灭火、修设备 | 艇的健康状况，决定能下多深、待多久 | 艇壳通电；把电分给探照灯或通电 |
| **打捞 / 潜水员** | 机械臂、挂钩、出舱采集 | 外面的实物——资源和真相都要靠他亲眼看、亲手拿回来 | 鱼叉枪、电击棒、信号火炬 |

- **岗位不锁死** ✅：谁都能操作任何位置，职业只给加成或专属技能。2～3 人也能玩，有人掉线别人能顶上。
- **人数缩放** ✅：少于 4 人时，部分系统自动化或放宽（比如轮机报警更早、漏水更慢）。具体数值玩起来再调。
- **升级跟着岗位走** ✅：船坞按舱位升级（声呐舱、轮机舱、机械臂、潜水装备……），每个人都有自己想攒钱买的东西。

## 五、出舱

✅ 要做。一个人在外面、只看得见探照灯照到的几米，舱里的人盯着声呐喊“你左边有东西在动”——这是这类游戏最吓人的时刻。

- **第一版：脐带缆出舱** —— 从艇上牵出来，活动半径二三十米。脐带缆供气、供电、通话。
  - 缆本身是资源：会被礁石缠住、被东西扯；缆断了就只剩潜水服里那点备用气。
  - 舱里有人管绞盘（谁空着谁管），能把人往回拉。
- **后期升级：自带气瓶** —— 不再拴着，能游得更远，但气瓶时间有限、通话变差。
- **潜水服内看到的东西** —— 有些东西只有出舱的人亲眼看得见（棺材、锁链、符），舱里的人只能听他描述。

## 六、威胁

### 海里的东西（分三级）
| 等级 | 例子 | 能怎么办 |
|---|---|---|
| 小型 | 鱼群、吸附在艇壳上的东西、寄生物、触须 | **能打死或打退** |
| 中型 | 掠食者 | **只能赶走或拖住** |
| 巨物 | 归墟深处的大家伙 | **打不了，只能躲** —— 熄灯、关机静默、躲进裂缝、抛载逃命 |

巨物的感知方式要让人有办法应对：听声音（主动声呐、机器噪音、敲击）、追光（探照灯）、感觉电流……
不同巨物怕的、被吸引的东西不一样，声呐员和老玩家能认出来。❓ 具体种类和行为待设计。

### 环境
- 压力：超过当前艇体耐压深度，艇壳开始吱嘎、渗水、裂。
- 漏水、短路、起火：轮机员的日常。
- 氧气、电量：见第八节。

## 七、反制与自制装备

### 背景 ✅
1998 年，国内枪支管得极严，一个下岗的船厂工人、一个退伍兵，**根本弄不到武器**。
东溟的合同上还写着：**“乙方不得携带任何武器、爆炸物登艇。”**——他们为什么不希望你能还手？

所以所有反制手段都是**自制**的：拿船厂车间的车床、电焊机、废料，照着渔民的土办法改。
九十年代沿海的电鱼、炸鱼都是常见的违法捕鱼手段，会做这些东西的人不少——这也是剧情里可以挖的人物关系。

### 装备清单（初稿）
| 装备 | 来历 | 谁用 | 作用 | 代价 |
|---|---|---|---|---|
| **鱼叉枪** | 渔民自制的橡皮筋鱼枪，钢叉是船厂车床车的 | 潜水员 | 近距离打小型生物 | 叉射出去要捡回来，不然就少一支 |
| **电击棒** | 电鱼器改的：电瓶 + 升压线圈 | 潜水员 | 贴身电退东西 | 耗潜水服电量 |
| **艇壳通电** | 同样是电鱼器的原理，接到艇壳的防护网上 | 轮机 | 把吸附在艇上的东西电下来、逼退中型生物 | 大量耗电 = 少了探照灯、少了续航 |
| **信号火炬 / 照明弹** | 渔船上的求救信号火炬，水下也能烧 | 潜水员 / 舱外发射管 | 照明、晃眼驱赶 | 数量有限 |
| **噪音诱饵** | 铁皮罐头里装发条闹钟和钢珠，或电池加蜂鸣器 | 声呐员（发射）/ 潜水员（扔） | 把听声音的东西引开 | 便宜，但会把东西招来附近 |
| **钢丝防护网** | 渔网和钢丝绳编的 | 潜水员 | 被动防护，挡一下 | 重，影响负重和游速 |
| **土炸药**（后期） | 炸鱼用的：采石场流出来的雷管、化肥炸药 | 任何人 | 唯一能逼退巨物一次的东西 | **极难弄到**；震伤艇体；声音巨大，会招来更多东西 |

- **在哪做** ✅：船坞车间。要材料（废钢、电瓶、铜线、火药……局内打捞或花钱买）+ 图纸（局外解锁，或从船厂某个老师傅那里学）。
- ❓ 自制装备违反合同——要不要做“被东溟发现”的风险？

## 八、局内资源

| 资源 | 消耗 | 补充 |
|---|---|---|
| **氧气** | 随时间，人越多耗得越快；出舱单算 | 船坞升级氧气罐；局内无法补充 |
| **电量** | 推进、探照灯、主动声呐、艇壳通电、电击棒 | 升级电池；轮机员决定分给谁 |
| **艇体耐久** | 压力、撞击、生物攻击 | 损管现场补（临时）；回船坞修（花钱） |
| **脐带缆** | 被缠、被扯、被咬 | 局内能接一次（要材料）；升级更结实的缆 |
| **消耗品** | 照明弹、诱饵、鱼叉、堵漏材料 | 船坞补给、车间自制 |
| **货舱 / 浮力** | 捞上来的东西有重量，越多越难上浮、越耗电 | 升级压载和货舱 |

## 九、养成与局外

两层，分开管：

| | 归谁 | 怎么来 | 花在哪 | 全灭会怎样 |
|---|---|---|---|---|
| **钱** | 团队存档 | 结算时卖掉打捞物 + 合同报酬 | 船坞：修艇、升级舱位、补给、买材料 | 这一局的货全丢，修艇费用大 |
| **局外点数** ❓（名字待定） | 每个玩家自己 | 每局结算，按完成度、贡献、发现的线索 | 个人技能、岗位专精、自制图纸、外观 | 不会丢 |

- ❓ 团队存档要不要有“破产 / 合同违约”的失败条件（类似每隔几单有一次大额还款）？母亲的医药费、船厂的债，都可以变成这个“必须挣够”的压力。
- ❓ 局外点数的名字可以和世界观挂钩，比如“香火”“阳寿”“账本上的一笔”……等剧情定了再起。

## 十一、联机技术方向

- **4 人，主机权威** ✅：一个玩家当主机，物理、生物、伤害、资源都由主机算，其他人只发操作。不架专门的服务器。
- **第一版已上线** ✅（2026-10-11，`scripts/net/`，说明见 README 的「联机」）：Godot 自带的多人 API + ENet 局域网 / 直连；
  大厅（建房、加入、挑岗位、开局）；舱内同步船员、潜艇、驾驶椅、探照灯、水密门。
- **Steam、归墟服务器先占位** ✅：大厅里按钮灰着，`net_backend.gd` 里各有一个空的后端。之后接 Steam（GodotSteam）做大厅、邀请和 P2P 中继；
  自己的服务器只做房间列表和中继转发。目标平台 Windows PC，上 Steam 最顺。
- ❓ 语音建议放进世界观里：
  - 舱内就近语音，隔着水密门变闷；
  - 出舱的人和艇里只能靠**水声电话**，带失真、断续；
  - 文字聊天作为备用。

### 对现有代码的影响
- ✅ `submarine.gd` 的运动和物理：主机算、广播；别人跟着算再校正。
- ✅ 水密门、探照灯、驾驶椅：先问主机。以后的新交互（声呐、配电、绞盘……）照这个路子接 `sub_session.gd`。
- ✅ 第一人称相机、角色：别人的身体用替身驱动 `crew_body.gd`。
- 剧情框架（`scripts/story/`）：剧情标记从个人变成团队；对话谁看得见、谁来选选项要重新定（还没动，岸上的场景现在只能单人）。
- 四个人现在都是周海生那张脸、同一身工装，要做区分（换脸、换衣服颜色）。
