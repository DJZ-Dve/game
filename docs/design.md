# 归墟 · 玩法设计（第二版 · 欧罗巴）

> 2026-10-12 方向重定：背景从 1998 年浙东沿海换到**木卫二（欧罗巴）冰下海洋**，中式神话和沉棺剧情不再用。
> 旧的设计和剧情归档在 `docs/archive/`（`design_v1_1998.md`、`story_1998.md`），只作素材。
> 标 ✅ 的是已经定下来的，标 ❓ 的是还没定、等拍板的（含提了但还没确认的建议）。

---

## 一、一句话

> 人类在木卫二冰下开发了很多年，靠一种只产于这片深海、能延寿的生物质维系着地球上无数人的寿命。
> 一场冰震，加上被人类噪音引来的东西，毁了线缆、毁了站点。供应断了。
> 你们是一群被高价征召的菜鸟，坐着升降机下到 20 公里的冰井底下，沿着断掉的线缆，去救人、去把“时间”捞回来。

**类型** ✅：潜艇 + 深海 + 微恐 + 模拟 + 经营 + 资源管理 + 4 人合作。
**不做** ✅：纯恐怖、PvP 对战（以后也许做“多艇间接对抗”的可选模式，现在不考虑）、塔科夫式长期仓库和公开匹配。
**参考**：潜渊症的系统深度 + 杀戮尖塔的节点地图 + 深海的写实氛围。和潜渊症的区别：第一人称 3D、写实、小潜艇、战斗少、**竖着往下走**。

### 设计支柱
1. **看不见外面** ✅ —— 高压冰水里舷窗只有拳头大，外面靠声呐、外部摄像头和传感器。信息拆给不同岗位，必须开口配合。
2. **人打不过海** ✅ —— 能反制，不能征服。巨物只能躲、只能偷（活检镖），小东西才能打。
3. **噪音** ✅ —— 这片海原本是安静的，是人类把它们吵醒的。每一次主动声呐、每一声引擎，都在重复人类犯过的错。
4. **每次下潜都在算账** ✅ —— 电、氧、热、艇体、浮力、保压罐、带回来的货。
5. **越走越深** ✅ —— 进度就是深度。艇壳的耐压深度是打开下一层的钥匙；越深，“时间”的等级越高。

## 二、世界

### 欧罗巴的硬设定 ✅
| 项目 | 数值 / 事实 | 玩法上的用处 |
|---|---|---|
| 结构 | 冰壳 → 液态海洋 → 岩石地幔 → 铁核。**海中间没有岩层**，从冰底到海底全是水 | 中层水体里的站只能悬在水里 |
| 冰壳厚度 | 游戏里定 **20 公里**（真实估计几公里到三十多公里，没有定论） | 冰井极其稀少的理由；约等于两座多珠峰 |
| 冰壳底部压力 | 约 **240 个大气压**（相当于地球海面下 2.4 公里） | 井口站从第一天起就是耐压舱，墙外就是高压海水 |
| 海的深度 | 估计 60～150 公里，海底约 **1500 个大气压**（比马里亚纳海沟还深） | 撑得起“越往下越难”和耐压升级 |
| 光 | 一丝都透不下来，冰下的海从来是全黑的 | 探照灯是这片海里第一束光；黑暗藏住远处的细节 |
| 潮汐 | 每 **3.55 天（约 85 小时）** 被木星揉一遍，冰壳周期性拉伸挤压 | 冰震有周期，可以做“潮汐表” |
| 冰层结构 | 上层冷脆（表面约 −160℃），下层较暖、缓慢对流；冰里可能夹着液态湖 | 冰下层的地形：倒挂冰脊、冰缝、盐水通道 |
| 辐射 | 表面一天 5 Sv 以上，致命；冰下几乎为零 | 海里的生物**没理由抗辐射**，别用这个设定 |
| 海山 | 引力小，山能长得很高（火星引力是地球三分之一，奥林匹斯山二十多公里高）；海底可能有被潮汐热推起来的巨型海底火山 | 中间多一块真正的“地面”；主缆不用垂 100 公里 |

### “时间”：最值钱的东西 ✅
**正式名**：欧罗巴压稳复合物（EPC）❓（名字可再改）
**俗称**：**“时间”** ——“这一罐是三年时间”“今天捞了多少时间”。我们拿命去换别人的时间。

#### 它是什么（给我们自己看的原理，保证设定不打架）
- **压力会把蛋白质挤变形。** 地球深海鱼会积累氧化三甲胺（TMAO）帮蛋白质抵抗压力，**生活得越深，体内越多**（真实研究结果）。
- 欧罗巴的压力是地球深海的好几倍，这里的生物演化出了强得多的一类分子：不只撑住蛋白质，还能把变形的蛋白质修好。
- **衰老的一个公认原因就是蛋白质出错、堆积、修不过来**（阿尔茨海默症是典型）。所以这类分子用在人身上能延缓衰老。
- 它只能**压住**衰老，不能阻止：**必须一直用；一断，被压住的衰老就开始往回追**。
- 现实参照：格陵兰睡鲨（冷水深海、代谢极慢、寿命约 400 年）；雷帕霉素（复活节岛土壤细菌的产物，能延长小鼠寿命）。

#### 为什么它这么值钱
- 源源不断地用，就能极端地拉长人的寿命——没有比这更值钱的东西。
- 用的人一辈子离不开它，需求永远不会停。
- **供应断了，地球上靠它活了很多年的权贵开始快速老去**——所以私人公司匆忙、毫无章法、不计代价地一批批往下派人。

#### 为什么必须一直来采，不能测个序就走
- 绝大部分微生物没法在实验室养活（地球上超过 99% 培养不出来）；欧罗巴的离开原来的压力、温度和共生伙伴就会死。
- 很多有效分子是整个共生群落合作的产物，光有基因序列造不出来。
- 每个热液区的物种都不一样，采完一个还要找下一个。
- 成品**会过期**：常温下慢慢失活，只能冻着运回地球，路上要好几年。囤不了货。

#### 等级：生物富集 ✅
沿食物链一级级富集（和汞、DDT 在食物链里的富集一样），再叠一条“越深越强”：

| 等级 | 来源 | 浓度 | 怎么拿 |
|---|---|---|---|
| 粗品 | 热液区的微生物菌毯 | 很低，到处都有 | 刮、采，量大价低 |
| 中级 | 吃菌毯的小生物 | 较高 | 捕捉、采样 |
| 高级 | 掠食者 | 高 | 危险 |
| 顶级 | 巨物 | 积累了几百年，最高、成分最复杂 | 极危险 |

- 低级的不稀缺，所以海里的生物都靠它进食，生态说得通；高级的稀缺，因为要漫长的时间和顶级掠食者来积累。
- **巨物本身就是证据**：它们活那么久、长那么大，正是因为体内积累了最多的“时间”。
- 人类不只吵醒了它们，**还在采它们的食物**。❓ 背景可埋：曾经有公司试图猎杀巨物——灾难是不是从那时开始的？

#### 从海里到针管 ✅
不能吃：有效成分是蛋白质一类的大分子，吃下去会被消化掉。**和胰岛素一样，只能打针，一辈子定期打。**

| 步骤 | 在哪 | 为什么 |
|---|---|---|
| 1. 活体采集 | 海里 | 装进**保压罐**；一失压，生物死了，分子也坏 |
| 2. 带回母港 | 潜艇货舱 | 保压罐重、耗电、占地方 |
| 3. 提取、纯化 | 站里的高压实验室 | 分子是在上千个大气压下演化出来的，到常压会慢慢失活，必须先在高压下提纯 |
| 4. 稳定化 | 实验室 | 化学修饰，让它在常压下撑住（现实中给蛋白质药物“加保护壳”） |
| 5. 冷链运回地球 | 冻着运好几年 | 仍会慢慢坏，有保质期 |

- **粗品**：跳过 3、4 步直接打进身体——矿工和潜水员私下在用。更耐冷、更能憋气、更扛压，但会上瘾、会出现幻觉（听见声音、在声呐上看见不存在的东西）。
  **富人用提纯的、安全的；矿工用粗品、付代价。**
- 不叫“强化”，叫“适应”：不会让人变成超人，避免和“人打不过海”冲突，也避免太像《沙丘》的香料。

#### 告诉玩家多少 ✅
| 层 | 内容 | 怎么告诉 |
|---|---|---|
| 必须知道（玩法） | 采什么、要保压、分等级、可以卖或提炼、自用有副作用 | 教程和界面提示，一两句话 |
| 最好知道（世界） | 要打一辈子针、断了会加速衰老、富人离不开它 | 靠展示：合同上“每克可为一位客户延续约若干个月”、电台广告“再多十年”、NPC 闲聊、站点最后的消息 |
| 想知道才看（原理） | 蛋白质变形、TMAO、衰老和蛋白质的关系 | 实验室终端里的资料条目 |

原则：**玩家永远不需要读一段说明才能玩**，但想追问“为什么”的人都能在游戏里找到答案。

### 站点网络：一棵树 ✅
**冰井往上通到地表，线缆往下、往外通到热液区。** 人类开发了很多年，线缆网络像一棵树，从极少的几个井口站往外、往下长，但也只占了欧罗巴很小一块；树之外是没人去过的黑暗。

| 类型 | 在哪 | 和外界的联系 | 数量 |
|---|---|---|---|
| **井口站** | 冰壳底部 | 冰井通往地表 | 极少。打一口 20 公里的冰井要好几年、花一大笔钱 |
| **缆站** | 挂在线缆上，往下、往外每隔一段一座 | 靠线缆供电、通讯，只能沿着缆走 | 很多，地图上的大部分站点 |
| **海山站** | 巨型海山的山顶，热液区旁边 | 主缆是它和上面唯一的联系 | 采“时间”的前线 |

- **冰井**：冰井沿着圆形井壁搭了一圈脚手架和升降机轨道，单程一个多小时。冰井不会自己开着，周围的冰会慢慢把它冻回去，全靠加热管一直加热。
- **悬在水里**：中层水体没有岩层，缆站是悬着的。现实原型是**深海潜标**（海底锚 + 缆 + 浮球，把仪器吊在几千米深的水里）和地中海的 KM3NeT 中微子探测缆。
  线缆上端固定在冰壳底部，下端锚在海底或海山上，绷得像琴弦；每座缆站自带浮力舱。
- **悬空对微恐是好事**：缆站随洋流慢慢晃、缆一直在响；窗外上面是黑的，下面也是黑的；浮力舱坏了，整座站会带着里面的人一直往下沉，直到被压碎。
- **线缆是中层水体唯一的路标**：跟着缆走安全，离开缆去找资源就有迷路的风险。
- **画面**：探照灯照着一根缆从头顶的黑暗里垂下来，又垂进脚下的黑暗里，往下看不到底；缆上偶尔缠着什么东西。
- ❓ 网络的起源（建议）：最早是政府和科学界建的观测阵列（冰井就是 IceCube 那样的钻孔，缆就是 KM3NeT 那样的探测缆），原本是用来**安静地听**的；
  后来阵列在热液区附近发现了生命和“时间”，公司跟着下来，沿着科学家的缆拉出更多分支。网络越来越大、越来越吵，最后它自己成了这片海里最吵的东西。

### 灾难 ✅
- **冰震**：潮汐冰震扯断线缆、震裂站点。
- **被噪音引来的东西**：几十年的钻探、引擎、主动声呐把一些生物引了过来，线缆似乎被什么东西毁了。
- 站点一座接一座失联，**每座站都留下了最后发回来的消息**：有的是求救，有的是一句没说完的话，有的只是一段噪音。
- 供应链断了，地球上的“时间”存货撑不了多久。

### 救援：一批又一批 ✅
- 人类召集了一批又一批的人去欧罗巴。**欧罗巴上还有人**：开发了这么多年，有人在站里结婚、生孩子，有第一代在欧罗巴出生的人——对他们来说，撤离回地球不是回家。
- **政府**的队伍按部就班：一段一段修线缆，不会贸然下去。
- **私人公司**为了保住自己的采集点和供应，开出高价工资，征召连菜鸟都要。风险自己扛。
- **我们是菜鸟**：业余、培训只有几天、装备破旧。正因为拿的是公司的高价，明知危险也得往没人修过的地方去。
- **张力**：公司合同要你回收采集设备和“时间”，站里的幸存者在等氧气。救人还是交货？

### 中文元素 ❓
倾向轻量保留：多国参与的欧罗巴开发，某个井口站叫“归墟站”，船员来自多个国家，现有的 MPFB2 人头可以继续用。神话部分不要。

## 三、海的分层 ✅

竖着往下走，每一层要更强的艇壳，“时间”的等级也越高。

| 层 | 深度 | 环境 | 主要压力 |
|---|---|---|---|
| **冰下层** | 冰壳底部附近 | 头顶是冰：倒挂冰脊、冰缝、盐水通道、冰里的湖；冰震后地形会变。井口站在这里 | 新手区，主要和艇本身较劲 |
| **中层水体** | 往下几十公里 | 上面没有冰，下面没有底，全黑，声呐打出去没回音；**线缆是唯一的路标**，缆站一座座挂在上面 | 大型生物；离开缆迷路就回不去 |
| **海山** | 巨型海山的山顶和山坡 | 脚下终于有了岩石；热液喷口、菌毯，生态最密集；海山站在山顶 | “时间”的主产区，最值钱也最危险 |
| **深渊** | 海山山坡往下 | 真正的海底 | 远期的谜和结局所在 ❓ |

## 四、地图与循环

### 节点地图（杀戮尖塔式，竖着往下）✅
不做无缝大地图。世界是一张**从上往下的剖面路线图**，每个节点是一个独立的小场景，玩家在节点之间选路线。

```
═══════════════ 冰壳 ═══════════════   0 km
              [井口站]  前进基地 · 母港
                 │ 线缆
     ◇ ───────── ┼ ───────── ◇         ← 母港周边：短下潜，去了回来
                 │
          ┌──────┼──────┐              ← 远航：岔路选线
          ○      ○      ?
          └──┬───┘      │
             ○          ◆  巨物领地
             └────┬─────┘
              [缆站 1]  修好 → 新母港
                 │
                ...
           [海山顶 · 海山站]
                 │
               深渊                     ???
```

- **地图本身就是剖面图**：竖着往下滚，旁边有深度刻度。往下走，冰壳从屏幕顶上消失，最后只剩黑暗和一根缆。光看地图就知道离家多远。
- **每层场景本身就不一样**：冰下层头顶是冰；中层水体上下都是空的；海山脚下才有岩石。不会出现“每次深入头顶都还有冰”。
- **每座站挂着它最后的消息**，这就是玩家选路线的理由，也是剧情揭开的方式。
- **节点一开始是“?”**：声呐员可以花电做一次远程扫描，看清前面几个节点；代价和下潜时一样——扫描会把东西招来。
- **节点之间的航行留在舱内**（类似 FTL 的跳跃）：加载下一个场景时，四个人还在舱里修东西、分配电、听声呐，偶尔出个小事件。
- **每次开新战役重新生成**：站点和主线固定，节点随机。

| 节点 | 相当于杀戮尖塔的 | 内容 |
|---|---|---|
| ○ 资源点 | 普通战斗 | 菌毯、矿、冰里的东西 |
| ▣ 残骸 | 宝箱 | 失联站点、失事潜艇丢下的东西，有日志 |
| ? 异常 | 问号事件 | 声呐上不该有的回声、一段求救信号、一艘漂着的空救生艇 |
| ◆ 巨物领地 | 精英 | 绕不过去时最难的一关，“时间”等级最高 |
| ✕ 巨物落 ❓ | 稀有 | 巨物死后沉下的尸体（参照鲸落），顶级资源点，但引来大量食腐的东西 |
| ◎ 缆站 | 篝火 | 修整、升级、存档 |

### 两种节奏 ✅
| 阶段 | 玩法 | 参考 |
|---|---|---|
| **母港周边** | 当前母港附近有几个节点，每次挑一个去作业，做完返回。冰震之后节点会变（塌了、新开了、来了东西） | 往返式，攒资源 |
| **远航** | 从这座缆站到下一座，中间是一段带岔路的路线。选了就不能回头，途中修整机会很少 | 杀戮尖塔、FTL |

- 每到一座失联缆站，把它和它那段线缆修好，变成**新的母港**：能存档、补给、升级。之后“返回”回的是最近这一站。
- 可以退回上一站：更安全，但资源更少。
- 每座失联站都是一个“案发现场”：吃了一半的饭、锁着的门、日志、幸存者（或者没有）。

### 返程也是玩法 ✅
- 货越多艇越重，上浮越费电；保压罐要耗电维持压力，上浮时外面的压力在变，要盯着。
- 回程的电和氧要在出发前算好。
- 下去时动静太大，回程路上可能有东西在等。
- 四个人对“贪多少”会有不同意见——这是联机最好玩的时候。

### 全灭：下一批人 ❓（建议）
- 你们这一队全灭了，公司就再派下一队（roguelite）。上一队修好的东西留着，他们的潜艇残骸会出现在地图上：能捞他们的货、听他们最后的录音。
- ❓ 战役的总失败条件：公司的耐心 / 资金耗尽？地球上的存货耗尽？

### 政府修复前线 ❓（建议）
- 政府的队伍沿着线缆一段一段往下修。修过的地方安全，但已经被搜干净了，报酬很低。
- 前线之外才有高价合同，但没人修过、没人知道下面有什么。
- 随着时间推移，前线慢慢往下推：玩家始终被逼着往前线外面走，难度曲线也自然有了。

❓ 一座母港待多久：固定几次短下潜就推进，还是玩家自己决定什么时候走？
❓ 一局时长：20 分钟左右快节奏，还是 40 分钟以上长下潜？

### 艇上

电力、生命维持、备件、实验室（提纯产能）、幸存者。

- **幸存者** ❓：救人占地方、耗氧，合同不一定给钱。

## 六、四个岗位 ✅

核心是**信息不对称**：每个岗位只看得到一部分，必须喊话。岗位不锁死，谁都能操作任何位置；2～3 人也能玩，部分系统自动化或放宽。

| 岗位 | 负责什么 | 掌握的信息 | 反制手段 |
|---|---|---|---|
| **驾驶** | 操艇、深度、压载、上浮、紧急抛载 | 只有仪表，外面全靠别人说 | 关机静默、躲进冰缝、抛载 |
| **声呐 / 导航** | 主动、被动声呐，海图和节点扫描，找目标，监听生物 | 唯一能“看见”外面的人。**主动声呐一开会暴露位置** | 决定开不开声呐；放噪音诱饵 |
| **轮机 / 损管** | 电力分配、氧气、暖气、保压罐、堵漏、灭火、修设备 | 艇的健康状况 | 艇壳通电；电分给谁 |
| **打捞 / 潜水员** | 机械臂、挂钩、出舱采集、活检镖 | 外面的实物——有些东西只有他亲眼看得见 | 采样工具、照明弹、电击 |

### 出舱 ✅
- 第一版：**脐带缆出舱**，活动半径二三十米，缆供气、供电、通话；舱里有人管绞盘。
- 后期升级：自带气瓶，能游得更远，时间有限、通话变差。
- 一个人在外面只看得见灯照到的几米，舱里的人盯着声呐喊“你左边有东西在动”——这是最吓人的时刻。
- 用了粗品“时间”的潜水员更耐冷、更能憋气，但他喊的“左边有东西”，可能是幻觉。**队友说的话还能不能信**，本身就很吓人。

## 七、威胁与微恐

### 微恐的原则 ✅
- 吓人的是**不知道**，不是被追：声呐上的影子、艇壳外的敲击声、通话里多出来的一个声音、失联站点的最后消息。
- 巨物**不一定有敌意**：不确定它想干嘛，比被追杀更吓人。
- 危险程度由玩家自己调：下多深、多吵、待多久、贪多少。
- 大部分时间是紧张地干活，偶尔失控。不堆 jump scare。
- ❓ 中后期钩子：2024 年有科学家在《科学》上警告“镜像生命”的风险（手性相反的细菌，免疫系统可能认不出）。如果欧罗巴生命恰好是反手性的，带回站里的活体样本就是真正的生物危害。

### 海里的东西
| 等级 | 能怎么办 |
|---|---|
| 小型（吸附物、寄生物、鱼群） | 能打死或打退 |
| 中型（掠食者） | 只能赶走或拖住 |
| 巨物 | 打不了，只能躲：熄灯、静默、躲进冰缝、抛载逃命 |

### 活检镖 ✅
取巨物的“时间”不靠杀：参照研究鲸鱼用的活检镖——悄悄靠近，打一镖取一小块组织，马上跑。游戏里最紧张的动作之一。
其他来源：巨物落、蜕下的壳、脱落的组织。

现有的两个巨物换成欧罗巴生物继续用：
- **「闷雷」**（`scripts/giant.gd`，行为第一版已做）：没有眼睛，只听声音。主动声呐的 ping 最响，然后是螺旋桨、压载泵、撞击、水密门。
- **「大眼」**（模型已完成）：可以是好奇的，靠过来看你的灯。❓ 行为待设计。

### 环境
- 超过耐压深度：艇壳吱嘎、渗水、裂。
- 漏水、短路、起火：轮机员的日常。
- 冰震：冰下层掉冰块、地形改变；❓ 和潮汐周期挂钩。

### 反制与工坊 ❓
没有正经武器，所有反制手段都是母港工坊用捞回来的零件拼的（采样工具改的、电击、照明弹、噪音诱饵、防护网、活检镖……）。具体清单待定。

## 八、开场 ✅

**个人开场**：每个玩家都看同一段开场（不分四个人四种），主角在地球上，有自己的动机。看完之后，**打开房间里的电脑 = 联机大厅**：接受应聘、寻找同事（建房 / 加入）。

### 地球：电视 ✅
主角在地球上的破旧住处看电视。职业跟海沾边（港口拖船、渔船声呐、钻井平台电工、商业潜水员之类）——在欧罗巴是菜鸟，但不是完全外行。
❓ 动机：比如家里有人急需“时间”却买不起（旧版“母亲等钱透析”可以转过来用）。

1. **广告**（私人公司）顺便讲了发现的历史：“二十年前，在木卫二冰下的深海，我们找到了它。”笑容满面的白发老人打网球、抱曾孙。“「时间」，再多十年。”小字飞快闪过：“需终身使用”。
2. **插播新闻**打断广告：欧罗巴冰震。

### 欧罗巴：冰震 ✅
主要用新闻里转播的“真实素材”拍（探测器远景、站点监控、冰井摄像头、水听器录音），画质差、有噪点、会断信号；只有一两个关键镜头用高画质。

| # | 画面 | 声音 | 关键 |
|---|---|---|---|
| 1 | 太空远景：巨大的木星，前面是白色的欧罗巴，表面一条裂纹慢慢延伸 | 新闻主播 | 木星占满半个屏幕 |
| 2 | 冰面上的井口塔，冰面隆起、裂开，冰屑在低重力下极慢地飘落 | **完全无声**（真空） | 欧罗巴独有的画面 |
| 3 | **冰井里：沿井壁一圈圈的灯，从上往下一盏一盏灭** ⭐ 高画质，第一个做 | 冰在结构里传来的巨响、钢架呻吟、一路往下的继电器声 | 一串灯往黑暗里灭下去 |
| 4 | 冰壳底部，站点挂在冰下：冰壳震裂，碎冰**往上漂**（冰比水轻） | 水里沉闷的轰鸣 | 科学正确，又很诡异 |
| 5 | 线缆绷断，一座缆站失去浮力，带着亮着的窗户慢慢沉进黑暗，最后只剩一个光点 ⭐ 高画质 | 站里的广播在喊，越来越远 | 整段的海报镜头 |
| 6 | 下沉的站最后照亮一瞬：旁边黑暗里有一个巨大的轮廓在动，只露一部分 | 水听器录到一声低频 | 不给看全 |
| 7 | 黑屏，一条条站点最后的消息 | 求救声、没说完的话 | 一个接一个失联 |
| 8 | 回到地球：电视换成另一条广告“高薪招募，无需经验”，公司标志和刚才那条是同一个 | 房间环境声 | 讽刺不用说 |
| 9 | 主角打开电脑 → 联机大厅（接受应聘、找同事）→ 冰井升降机里四个人第一次见面，游戏开始 | | 接上教程 |

❓ 招募广告里要不要让公司老板本人出镜：看起来四十岁，其实一百多岁。

### 下井 ✅
1. 四个菜鸟坐升降机沿**政府刚刚重新打通的那口冰井**往下，去前进基地报到。窗外是一个多小时的冰壁（实际压成几分钟），灯一盏盏往后滑，冰还在响。
2. ❓ 中段要不要再来一次冰震：把这口井也封了，救援的人自己也被困在下面，故事从“救人”变成“一起活下去”。
3. 到了基地，认识彼此、领装备、第一次出港。这一段同时是教程。

## 九、控制规模：不做 3A ✅

**原则：玩法的大部分时间在潜艇里和海里，站只是“家”，越小越好。黑暗、声音和界面替我们省掉大部分美术。**

| 想要的 | 省事的做法 |
|---|---|
| 巨大的站点 | 前进基地不大，**里面只剩十来个人**——既省人力，也更孤独 |
| 站的很多房间 | 只建 3～4 个能走进去的房间：**月池船坞**（核心）、通讯室、实验室、一条宿舍走廊。其他门关着，在**站的示意图界面**上管（类似 FTL 的舱室图） |
| 人流 | 不做人流。3～5 个关键 NPC 固定在岗位上；其他人只是名单上的名字、广播里的声音、走廊远处的说话声、门缝里的灯 |
| 船坞升级 | 升级直接体现在潜艇上（换部件、换外观）+ 一个终端界面；不做吊车动画 |
| 大地图 | **节点地图**：每个节点是一个小场景，模块拼 + 随机变化。现有的 `deep_sea.tscn` 就是一个现成的节点 |
| 很多失联站点 | **和基地共用一套模块化素材**（走廊、舱室、气闸、月池），只是更暗、进了水、东西乱。一套素材用到底 |
| 站的外观 | 从潜艇里看出去只是黑暗里的一片灯光和轮廓，不需要细节 |
| 冰井升降机 | 一段井壁 + 一圈脚手架做成模块，无限重复；镜头在轿厢里。第一版可以先用黑屏加文字和声音代替 |

**开发优先级** ✅：潜艇舱内（已有）> 一个资源点节点（已有一部分）> 节点地图 > 月池船坞 > 基地的几个房间 > 失联站点（复用基地素材）> 冰井开场（最后做）。

## 十、联机 ✅

- **只做合作**，4 人，主机权威：一个玩家当主机，物理、生物、伤害、资源都由主机算。不架专门的服务器。
- **第一版已有**（`scripts/net/`，说明见 README 的「联机」）：ENet 局域网 / 直连；大厅；舱内同步船员、潜艇、驾驶椅、探照灯、水密门。
- **下一步：局域网房间自动发现**（现在要手动填 IP）。
- 之后接 Steam（GodotSteam）：大厅、邀请、P2P 中继，玩家之间不用开端口，零服务器成本。Steam 不替我们跑服务器，主机还是玩家自己。
- ❓ 语音放进世界观：舱内就近语音、隔着水密门变闷；出舱只能靠水声电话，带失真、断续；文字聊天备用。

### 对现有代码的影响
- 潜艇物理、水密门、探照灯、驾驶椅的同步：照旧。新交互（声呐、配电、绞盘、保压罐……）照这个路子接 `sub_session.gd`。
- 剧情框架（`scripts/story/`）、办事处、宿舍：都是旧背景的，要按新背景改或替换。办事处 → 基地的某个房间；`office.tscn`、`dorm.tscn` 里的材质和道具能拆着用。
- 四个人现在都是同一张脸、同一身工装，要做区分。
